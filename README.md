# Directorio Person

Sistema de gestion del directorio de personas de la base de datos AdventureWorks.

Proyecto academico de la asignatura **Gerencia de Proyectos de Software**.

## Descripcion

Aplicacion web que permite consultar y administrar la informacion de personas
del schema `Person` de AdventureWorks, junto con sus correos electronicos,
telefonos y direcciones postales.

## Stack tecnologico

| Capa | Tecnologia |
|---|---|
| Base de datos | SQL Server 2025 Express |
| Backend | Node.js 20 + Express |
| Driver | mssql |
| Frontend | React 18 + Vite |
| Estilos | Tailwind CSS |
| Autenticacion | JWT + bcrypt |

## Requisitos previos

- SQL Server 2025 Express
- SQL Server Management Studio 22
- Node.js 20 LTS o superior
- Git
